PSEMs
=====

A PHP project. This repository contains the initial structure for PSEMs.

Getting started
---------------

1. Copy .env.example to .env and update values:

   cp .env.example .env

2. Install dependencies (if any):

   composer install

3. Start your local server (for example):

   php -S localhost:8000 -t public

Files added
-----------

- .env.example — example environment variables
- .gitignore — recommended ignores for PHP projects
- .htaccess — Apache rewrite rules
- composer.json — Composer project metadata
- README.md — this file
